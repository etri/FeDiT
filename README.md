## FDTFW
_FDTFW 프로젝트_ 는 2022년 4월 시작하였습니다.

### FDTFW Modules
* `CMFW`: 지능형 디지털 연합트윈 공통 기능 프레임워크
* `OPFW`: 지능형 디지털 연합트윈 운용 및 예측 프레임워크
* `CDFW`: 지능형 디지털 연합트윈 객체 구성 프레임워크
* `OSFW`: 지능형 디지털 연합트윈 개방형 서비스 프레임워크

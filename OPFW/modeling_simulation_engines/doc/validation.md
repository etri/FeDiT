# 확인 결과

이 저장소의 실행 파일 묶음과 예제로 확인한 내용이다. 실행 PC는 RTX 5080 한 장이다. 이 GPU는 빌드 대상 밖이라 드라이버가 GPU 코드를 컴파일하며 돌았으므로, 시간은 참고로만 본다.

## 1. 배포 묶음으로 예제 실행 (2026-10-06)

저장소 폴더를 새 위치에 복사한 뒤, 실행 스크립트(`scripts/run_case.*`)로 예제 5개를 돌렸다. 스크립트가 묶음을 직접 풀었다.

- Windows: PATH에서 CUDA 툴킷을 빼서 드라이버만 있는 PC와 같은 조건으로 돌렸다.
- Linux: CUDA 런타임(`libcudart`) 말고는 CUDA 라이브러리가 없는 `nvidia/cuda:12.1.0-base-ubuntu22.04` 이미지에 `libgomp1`과 `xz-utils`만 설치하고, `LD_LIBRARY_PATH` 없이 돌렸다. 실행 파일은 묶음 안의 라이브러리(NVRTC 포함)를 RUNPATH로 찾았고, 시스템에서 가져온 것은 GPU 드라이버(`libcuda`)와 `libgomp`뿐이었다.

판정 기준은 실행 스크립트와 같다. 종료 코드 0이고 마지막 결과 코드가 `RC : 0`이면 통과다. LBM_DEM은 로그에 `nan`·`inf`가 없어야 한다.

| 예제 | Windows | Linux | 결과 크기 |
| --- | --- | --- | --- |
| 01 다성분 (짧은 실행) | 통과, 91초 | 통과, 107초 | 4.2 GB |
| 02 다상 (짧은 실행) | 통과, 10초 | 통과, 2초 | 88 MB |
| 03 농도확산 (원래 길이) | 통과, 41초 | 통과, 30초 | 0.5 MB |
| 04 복합 열전달 (짧은 실행) | 통과, 57초 | 통과, 68초 | 1.4 GB |
| 05 유체-DEM 연성 (짧은 실행) | 통과, 16초 | 통과, 32초 | 442 MB |

일부 시간에는 첫 실행의 GPU 코드 컴파일 시간이 들어 있다(Windows 03 등). 02의 로그에는 진단 출력 `averaged_vel = -nan`이 한 줄 있으며, 결과 파일에는 NaN이 없다. Windows 묶음은 약관·고지를 넣어 다시 만든 뒤 03과 05를 다시 돌려 통과를 확인했다(실행 파일은 같다).

## 2. 다시 링크한 Windows 실행 파일

공개 묶음의 Windows 실행 파일은 빌드 PC 경로를 지우려고 링크 옵션 하나(`/PDBALTPATH:%_PDB%`)만 바꿔 다시 링크했다. 그 전 빌드와 같은 결과를 내는지 03 농도확산과 05 유체-DEM 연성으로 확인했다. 결과 파일(`.vtm`, `.vtu`, `.vtk`)은 두 예제 모두 바이트 단위로 같았다. 재시작 파일(`continue/*.bin`)만 달랐는데, 다른 바이트는 재시작 파일에 함께 기록되는 메모리 주소 값이었고 물리량과는 관계가 없다.

## 3. Windows와 Linux 결과 비교 (2026-10-02)

같은 입력을 Windows 빌드(CUDA 11.7)와 Linux 빌드(CUDA 12.1)로 돌려 배열별로 비교했다.

| 예제 | 비교 결과 (마지막 저장) |
| --- | --- |
| 01 다성분 | 셀 단위로는 다르고 통계는 같다 (아래) |
| 02 다상 | 모든 배열이 비트 단위로 같다 |
| 03 농도확산 | 모든 배열이 비트 단위로 같다 |
| 04 복합 열전달 | 모든 배열이 비트 단위로 같다 (격자 2단계 모두) |
| 05 유체-DEM 연성 | 유체 결과는 비트 단위로 같다. 입자 결과는 `min_normal` 하나만 다르다 |

01 다성분은 계산 전 초기 조건부터 경계면 근처 값이 마지막 자리(4.4e-16)에서 달랐다. 두 컴파일러의 수학 함수 반올림 차이로 보며, 이 차이가 계산 중에 커졌다. 2,880 스텝에서 위쪽 영역(z > 400)의 `order_parameter1` 최솟값은 Windows 0.909, Linux 0.904이고 표준편차는 7.06e-3, 7.08e-3이다.

05의 `min_normal`은 바닥 쪽 입자 3,996개에서 Windows는 0, Linux는 다른 값이다. 입자를 만들 때 정해지는 값이고, 위치·속도·가속도·힘 등 나머지 입자 결과는 모두 같았다.

## 4. 농도확산: 해석해 비교

예제 03은 해석해가 있는 벤치마크다(Zhang et al., 2012, PRE 85, 016701, III.B). 정상 상태 결과를 해석해와 비교한 오차는 Re = Pe = 10에서 E_u 4.8e-3, E_C 3.2e-4다. 조건별 표와 수렴 차수는 [`examples/03_concentration_diffusion/README.md`](../examples/03_concentration_diffusion/README.md)에 있다.

## 5. 복합 열전달: 판정 항목 5개 (2026-10-02)

예제 04를 원래 길이(64,000 스텝, 저장 101회)로 같은 커밋의 Windows 빌드로 돌리고, 사전 자체 시험과 같은 판정 절차로 5개 항목을 계산했다. 기준 해는 상용 해석 결과이며 이 저장소에는 넣지 않았다.

| 항목 | 합격 기준 | 결과 | 판정 |
| --- | --- | --- | --- |
| 뜨거운 벽 평균 Nu 오차 | 2% 이하 | 0.355% | 통과 |
| 에너지 보존 (뜨거운 벽과 차가운 벽의 Nu 차) | 1% 이하 | 0.163% | 통과 |
| x 방향 최대 속도 오차 | 5% 이하 | 0.03% | 통과 |
| y 방향 최대 속도 오차 | 5% 이하 | 3.35% | 통과 |
| 최대값 위치 오차 | 0.0156 L (1셀) 이하 | 0.0043 L | 통과 |

실행에 2,404초(40분)가 걸렸고 결과는 31.3 GB였다.

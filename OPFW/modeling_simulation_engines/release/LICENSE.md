# 실행 파일 사용 약관

## 적용 대상

이 약관은 `release/`의 실행 파일 묶음에 든 이에이트(주)(E8IGHT Co., Ltd.)의 구성요소(이하 "실행 파일")에 적용된다. 실행 파일은 다음과 같다.

- Windows: `LBM_Runtime.exe`, `LBM.dll`, `LBM_SDK.dll`, `LBM_Lattice_Generator.dll`, `LBM_DEM_Runtime.exe`, `LBM_DEM.dll`, `LBM_DEM_SDK.dll`, `LBM_DEM_Lattice_Generator.dll`
- Linux: `NFLOW_LBM`, `NFLOW_LBM_DEM`, `libLBM*.so`, `libLBM_DEM*.so`

묶음에 함께 든 제3자 구성요소(HDF5, NVIDIA CUDA 런타임, NVIDIA NVRTC)는 이 약관이 아니라 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)에 적은 각 라이선스를 따른다.

저장소의 LGPL-2.1 선언(`LICENSE`, `LICENSE_KR.md`)은 실행 파일에 적용되지 않는다. 실행 파일은 오픈소스가 아니다. 해석기의 물리 식 부분은 `src/`에 LGPL-2.1-only로 따로 공개한다.

## 1. 무료 사용

다음 사용자는 비영리 목적의 연구, 교육, 평가, 시험에 한해 실행 파일을 무료로 설치, 실행, 복제할 수 있다. 2조의 영리 기업(법인과 개인사업자)은 아래 어느 항목에 해당하더라도 이 조의 사용자가 아니다.

- 대학과 그 밖의 비영리 교육기관
- 비영리 연구기관
- 국가기관, 지방자치단체, 공공기관
- 개인 (영리 활동이나 사업에 쓰지 않는 경우)

## 2. 계약이 필요한 사용

다음 사용에는 이에이트(주)와 별도 계약이 필요하다.

- 영리 기업(법인과 개인사업자)의 사용. 내부 연구와 평가를 포함한다
- 실행 파일을 포함하거나 이용하는 제품·서비스의 제공
- 실행 파일을 이용한 영리 목적의 해석 용역
- 1조의 사용자라도 영리 목적으로 쓰는 경우

## 3. 재배포

1조의 사용자는 비영리 목적에 한해 실행 파일 묶음을 재배포할 수 있다. 묶음은 수정하지 않아야 하며, 묶음 안의 이 약관과 `THIRD_PARTY_NOTICES.md`를 함께 제공해야 한다. 이 약관은 당사 실행 파일의 재배포만 허락한다. 묶음에 든 제3자 구성요소의 재배포는 각 구성요소의 라이선스가 허용하는 범위에 따른다.

## 4. 금지 사항

- 관련 법령이 허용하는 범위를 넘는 역설계, 디컴파일, 디스어셈블
- 저작권 표시와 이 약관의 삭제·변경
- 실행 파일을 수정한 판의 배포
- 묶음에 든 NVIDIA 구성요소를 이 실행 파일과 함께 쓰는 것 외의 용도로 쓰는 것

## 5. 특허

이에이트(주)는 이 약관에 따라 허락된 범위에서 실행 파일을 사용하는 데 필요한 한도에서만 관련 특허의 실시를 허락한다. 그 밖의 특허권은 모두 유보한다.

## 6. 보증과 책임

실행 파일은 있는 그대로 제공한다. 이에이트(주)는 실행 파일과 해석 결과의 정확성, 특정 목적에의 적합성을 보증하지 않으며, 관련 법령이 허용하는 범위에서 실행 파일의 사용으로 생긴 손해에 책임을 지지 않는다.

## 7. 종료

이 약관을 위반하면 사용 허락은 자동으로 끝난다. 이때 사용자는 가지고 있는 실행 파일과 복제본을 모두 삭제해야 한다.

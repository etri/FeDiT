# 다상 해석기 물리 식 (multiphase)

이 해석기는 한 물질의 액상과 기상이 함께 있는 유동을 격자 볼츠만법(D3Q27)으로 푼다. 두 상은 Peng-Robinson 상태방정식에서 얻은 유효 질량 ψ 사이의 상호작용 힘으로 나뉘고, 벽과의 상호작용 세기로 젖음을 나타낸다. 이 폴더에는 그 계산에 쓰이는 식만 헤더로 옮겼다.

## 파일별 내용

D3Q27 격자 속도 e_i와 가중치 w_i, 내적 `dot`은 다섯 해석기가 함께 쓰는 `../common/d3q27.hpp`와 `../common/nflow_formula.hpp`에 있다.

| 파일 | 담은 식 |
|---|---|
| `equation_of_state.hpp` | Peng-Robinson 상태방정식의 압력 p(ρ)와 유효 질량 ψ = sqrt(-2(p - ρ/3)). 이심 인자는 0.344로 고정되어 있다. |
| `force.hpp` | 유효 질량 ψ로 만든 4차 상호작용 힘(유체-유체 항, 벽 방향의 유체-벽 항, κ·λ 조정 항), 중력과 운동량 원천을 더하는 체적력, 분포함수 쪽 힘 항 w_i F·[3(e_i - u) + 9(e_i·u)e_i]. |
| `collision.hpp` | 중심 모멘트 충돌에 다상 모델이 더하는 항. 밀도에 따라 기상과 액상 사이를 선형 보간한 동점성계수, 그리고 힘 F로 정해지는 충돌 후 1차·3차·5차 중심 모멘트. 충돌 커널 자체는 들어 있지 않다. |
| `macroscopic.hpp` | 분포함수에서 밀도와 속도를 구하는 식. 속도에는 힘의 절반을 더해 보정한다. 유체 노드용과 경계 식이 읽는 내부 노드용 두 형태가 있으며, 수식은 같지만 계산 순서가 달라 반올림 결과가 다르므로 둘 다 두었다. |
| `wetting.hpp` | 고체 노드의 밀도를 이웃 유체 노드 밀도의 가중 평균으로 정하는 젖음 처리. 이 밀도로 고체 노드의 유효 질량을 구하고, 힘 식의 벽 항이 벽 상호작용 세기 G_w와 함께 쓴다. |
| `boundary.hpp` | 대류 유출 경계. 내부 노드 속도로 유출 속도 U를 표본 추출하고, 분포함수와 힘을 ∂φ/∂t + U ∂φ/∂n = 0의 3차 단측 차분으로 외삽한다. 외삽을 쓰지 않는 경우에 쓰는 기상 쪽 대체식과 그 선택 조건도 들어 있다. 대체식에 들어가는 평형분포 값은 호출하는 쪽에서 준다. |

## 주요 기호

| 기호 | 뜻 |
|---|---|
| f_i | 방향 i의 분포함수 |
| e_i, w_i | 격자 속도와 가중치 |
| ρ, u | 밀도와 속도 (격자 단위) |
| p | 상태방정식 압력 |
| ψ | 유효 질량 |
| a, b | Peng-Robinson 상수 (격자 단위) |
| T_c, T_s | 임계 온도와 포화 온도. 환산 온도 T_s/T_c가 식에 들어간다. |
| κ, λ | 상호작용 힘 식의 조정 계수 |
| G_w | 유체-벽 상호작용 세기 |
| F | 상호작용 힘과 체적력을 합한 힘 |
| ρ_l, ρ_v / μ_l, μ_v | 액상과 기상의 밀도 / 점성계수 |
| U | 유출 경계의 평균 유출 속도 |

## 참고 문헌과 모델

- 고체 노드 밀도의 가중 평균(젖음 처리): Liu, Y., Yao, Y., Li, Q., Zhong, X., He, B., & Wen, B. (2023). Contact angle measurement on curved wetting surfaces in multiphase lattice Boltzmann method. Langmuir, 39(8), 2974-2984.
- 상태방정식: Peng-Robinson 상태방정식.
- 상호작용 힘: 유효 질량 ψ를 쓰는 pseudopotential 계열 모델.
- 충돌: 중심 모멘트 충돌과 중심 모멘트 공간에서 넣는 힘 항.

각 함수는 해석기와 같은 연산 순서로 옮겼다. `nflow::real`이 `double`일 때 해석기와 같은 값을 낸다.

이 폴더는 해석기의 물리 식 부분만 담았으며, 단독으로 빌드되는 해석기가 아니다. 격자 자료구조, 이웃 탐색, streaming, 충돌 커널, 시간 진행은 들어 있지 않다. 평형분포는 비압축 해석과 같은 표준 평형분포라 넣지 않았다.

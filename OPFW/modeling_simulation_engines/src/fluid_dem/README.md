# 유체-DEM 연성 해석기: 물리 식

유체-DEM 연성 해석기는 물의 흐름을 격자 볼츠만 방법(LBM)으로, 물속 입자의 운동을 이산요소법(DEM)으로 풀고 두 계산이 매 시간 단계 힘을 주고받게 한다. 유체는 입자에 항력과 압력 구배 힘을 주고, 입자는 그 반작용을 유체에 체적력으로 돌려준다. 반경이 서로 다른 입자를 한 계산에서 함께 다룰 수 있고, 큰 입자 하나로 작은 실제 입자 여러 개를 대신하는 coarse-grain 계산도 할 수 있다.

이 폴더에는 그중 DEM 쪽 식만 담았다. 입자끼리의 접촉력, 입자와 벽의 접촉력, 유체가 입자에 주는 힘과 그 반작용, 가까운 입자·벽 사이 유체막의 윤활력이다. 모든 식은 배정밀도(`double`)에서 해석기 코드와 같은 연산 순서로 옮겼다.

## 접촉력

접촉 하나는 겹침 δ, 단위 법선 n, 접촉점의 상대속도 v(법선 성분 v_n, 접선 성분 v_t)로 계산한다. 접촉점은 겹친 구간의 가운데에 둔다.

- 법선 힘: F_n = k_n δ^(3/2) n + γ_n v_n. 입자끼리의 접촉에는 응집력 −π R* δ CED n을 더한다.
- 법선 강성과 감쇠: k_n = (4/3) E* √R*, γ_n = −(2/3)√15 R*^(1/4) √(m* E*) ln e_n δ^(1/4) / √(π² + (ln e_n)²). e_n이 0에 가까우면 ln e_n / √(π² + (ln e_n)²)의 극한값 −1을 쓴다.
- 접선 힘: 시험값 F_t* = k_t ξ + γ_n v_t, k_t = 8 G* √(R* δ). |F_t*|가 쿨롱 한계 μ|F_n|을 넘으면 F_t를 한계 크기로 자르고, ξ를 그 힘에 맞는 값 (F_t − γ_n v_t)/k_t로 되돌린다.
- 접선 변위 ξ: 지난 하위 단계의 값을 현재 접평면에 투영한 뒤 v_t Δt를 더한다. 새 접촉은 0에서 시작한다.
- 회전: 접선 힘이 만드는 각가속도 (F_t × R n)/I, I = 0.4 m R².
- 구름 저항: T_r = −μ_r |F_n| R ω/|ω|. 한 하위 단계에 쓸 수 있는 크기는 I|ω|/Δt까지다. 회전을 멈추는 것 이상으로 방향을 뒤집지 않게 하려는 상한이다. 벽 접촉이 먼저 쓰고 입자 접촉은 남은 만큼만 쓴다.

입자끼리와 입자-벽은 다음이 다르다.

| 항목 | 입자-입자 | 입자-벽 |
| --- | --- | --- |
| 유효 반경 R* | R_i R_j / (R_i + R_j) | 입자 반경 R_i |
| 유효 질량 m* | m_i m_j / (m_i + m_j) | 입자 질량 m_i |
| μ, μ_r, e_n | 입자 i의 값 | 벽 재료의 값 |
| 응집력 | 있음 | 없음 |
| 쿨롱 한계 적용 | 항상 | 한계가 양수일 때만 |
| 여러 접촉 | 힘을 더한다 | 벽면을 덮은 작은 벽 구들과 각각 접촉하고, 힘과 각가속도를 닿은 개수로 평균한다 |

E*와 G*는 두 재료의 영률 E와 푸아송 비 ν로 E* = E_i E_j / [E_j(1 − ν_i²) + E_i(1 − ν_j²)], G* = G_i G_j / [G_j(2 − ν_i) + G_i(2 − ν_j)], G = E / [2(1 + ν)]로 구한다.

## 유체력과 반작용

입자 위치의 유체 밀도 ρ_f, 동점성 ν_f, 속도 u_f, 압력 구배 ∇p를 받아 계산한다. μ_f = ρ_f ν_f다.

- 입자 레이놀즈 수: 입력 `particle_reynolds_viscosity`가 `legacy`(기본)이면 Re = ρ_f (2R/k) |u_f − v_p| / 0.001로, 물의 점성 0.001 Pa·s를 쓴다. `config`이면 Re = (2R/k) |u_f − v_p| / ν로, 유체 재료의 동점성을 쓴다.
- 항력: F_d = λ (u_f − v_p), λ = 3π (2R) μ_f (1 + 0.15 Re^0.687) k². 반경 R = k R_real인 입자 하나는 실제 입자 k³개를 대신하므로 항력도 k³배여야 한다. 모델 지름을 쓰는 Stokes 항력이 이미 k배이므로 나머지 k²를 곱한다. 입력 `coarse_grain_drag_correction`(기본 켬)을 끄면 k² 대신 1을 쓴다. 배율 k는 입력 `particle_radius_scaling_factor`(기본 1)다.
- 항력 임펄스 제한: x = Δt ε_f λ / m이 1을 넘으면 항력에 1/x를 곱한다. 명시적 시간 적분에서 한 하위 단계에 입자 속도가 유체 속도를 지나치지 않게 하는 장치이고, x ≤ 1이면 항력은 그대로다.
- 압력 구배 힘: F_p = −V ∇p.
- 입자가 받는 유체력: ε_f (F_d + F_p), ε_f = 1 − ε_p.
- 반작용: 유체 셀마다 f = −Σ w V_cell (F_d + F_p)를 체적력으로 더한다. w는 입자와 셀 중심 사이의 이산 델타 가중치, V_cell = Δx³이다. 반작용에는 ε_f를 곱하기 전의 힘을 쓰고, 가중치가 10⁻⁶보다 작은 입자는 건너뛴다.

## 윤활력

입자와 이웃 입자, 또는 입자와 벽 사이의 간극 h가 최소 간극 max(10⁻⁵Δx, 10⁻⁶R_i)와 h_c = 0.1 d_p(= 0.2 R_i) 사이일 때, 얇은 유체막이 상대 운동을 막는 힘을 더한다.

- F = −a_sq v_n − a_sh (2/(h + D))² v_t
- a_sq = 1.5π μ D [0.25 D/h + 0.45 L + (9/84)(h/D) L], a_sh = 0.5π μ D L · 0.25 (D + h)², L = ln(max(0.5 D/h, 10⁻¹²))
- 이웃 입자: D = 4 R_i R_j/(R_i + R_j), 상대속도는 v_i − v_j, 방향은 두 중심을 잇는 단위 벡터다.
- 벽: D = 4 R_i, 상대속도는 v_i, 방향은 벽 법선이다. 범위 안의 벽 구들의 힘을 그 개수로 평균한 뒤 이웃 입자의 힘을 더한다.
- μ = ρν는 입자가 있는 셀의 유체 점성이고, μ < 10⁻⁹이면 윤활력을 주지 않는다. 윤활력은 입자에만 작용하고 유체로 반작용을 돌려주지 않는다.

## 주요 기호

| 기호 | 뜻 |
| --- | --- |
| δ | 두 물체의 겹침 |
| n | 단위 법선(상대 물체에서 입자 i 쪽) |
| R, m, I | 입자 반경, 질량, 관성 모멘트 |
| R*, m*, E*, G* | 유효 반경, 유효 질량, 유효 영률, 유효 전단 탄성계수 |
| e_n | 반발계수 |
| μ, μ_r | 미끄럼 마찰계수, 구름 마찰계수 |
| CED | 응집 에너지 밀도 [J/m³] |
| ξ | 접선 변위(접촉 이력) |
| Δt | DEM 하위 단계 시간 간격(유체 시간 단계를 DEM 반복 횟수로 나눈 값) |
| ε_p, ε_f | 입자 주변의 고체 분율, 유체 분율 |
| k | 입자 크기 배율(모델 반경 / 실제 반경) |
| λ | 선형 항력 계수 |

## 넣지 않은 것

- 자유수면 처리 전부: 질량과 채움 분율 갱신, 계면 셀 처리, 자유수면 경계. 유체력 보간에서 기체 셀을 다루는 방식, 기체 셀에 반작용을 주지 않는 처리, 입자나 이웃 입자가 기체 셀에 있을 때 윤활력을 빼는 처리도 자유수면 처리에 속하므로 넣지 않았다.
- 유동 계산: LBM 충돌과 이동, 반작용을 유체 운동량 식의 체적력에 더하는 부분, 입자 체적 분율에 따른 유체 점성 보정.
- 접촉 판정 기하(겹침과 법선 계산), 접촉 이력 저장과 관리, 이웃 입자 탐색.
- 유체 값을 입자 위치로 보간하는 식과 그 가중 함수, 셀과 입자의 체적 분율 계산.
- 입자의 시간 적분(가속도, 속도와 위치 갱신, 체적 분율에 따른 속도 감쇠).
- 윤활력 간극 계산(접촉 판정 기하와 같은 이유), 단위 변환.

## 참고한 모델

- Hertz–Mindlin 접촉 모델. 접선 강성은 Mindlin–Deresiewicz 이론의 완전 고착(full-stick) 형태를 쓴다.
- Sakai의 coarse-grain 입자 모델(항력 k² 보정).
- Schiller–Naumann 항력 보정식(1 + 0.15 Re^0.687).

이 폴더는 해석기의 물리 식 부분만 담았으며, 단독으로 빌드되는 해석기가 아니다.

# 해석기 물리 식 소스

해석기 5종의 물리 모델을 계산하는 식을 C++ 헤더로 정리한 것이다. 각 해석기가 평형분포, 충돌, 힘, 경계값, 거시량을 어떻게 계산하는지, 유체-DEM 연성 해석기는 입자 접촉력과 유체력을 어떻게 계산하는지를 담았다. 라이선스는 LGPL-2.1-only다.

이 폴더는 해석기 전체가 아니다. 격자 자료구조, 유동 계산의 공통 핵심부(공통 충돌 커널, 난류 모델, 다중 격자 처리, 분포 이동), 격자 생성, 입출력은 넣지 않았다. 그래서 이 소스만으로는 해석기를 빌드할 수 없다. 해석기를 실행하려면 [`release/`](../release/)의 실행 파일을 쓴다.

## 구성

| 폴더 | 해석기 | 담은 식 |
| --- | --- | --- |
| [`multi_component/`](multi_component/) | 다성분 (2성분) | 상장(order parameter) 충돌, 유동 충돌의 힘 항, 표면장력 등 경계면 힘, 압력 필터, 혼합 물성, 젖음 조건 |
| [`multiphase/`](multiphase/) | 다상 | Peng-Robinson 상태방정식, 상호작용 힘, 힘 항, 혼합 점성, 젖음 조건, 대류 유출 경계 |
| [`concentration_diffusion/`](concentration_diffusion/) | 농도확산 | 농도 분포의 평형분포·충돌·비평형 재구성(난류 확산 포함), 농도 경계조건, 농도 계산 |
| [`conjugate_heat_transfer/`](conjugate_heat_transfer/) | 복합 열전달 | 온도 분포의 평형분포·충돌·비평형 재구성(난류 열확산 포함), 재료별 열물성, 부력, 벽 열 조건 |
| [`fluid_dem/`](fluid_dem/) | 유체-DEM 연성 | 입자-입자·입자-벽 접촉력(법선·접선·감쇠·응집·구름 저항), 윤활력, 유체가 입자에 주는 힘과 유체로 돌려주는 반작용 |
| [`common/`](common/) | 공통 | 실수 형식과 벡터(`nflow_formula.hpp`), D3Q27 격자 속도와 가중치(`d3q27.hpp`) |

유체-DEM 연성 해석기의 자유수면 처리는 넣지 않았다. 다상·다성분의 유동 분포 평형분포는 비압축 해석과 같은 표준식이라 넣지 않았다. 난류 확산·열확산 식은 난류 점성 ν_t를 입력으로 받으며, ν_t를 구하는 난류 모델은 넣지 않았다. 각 폴더의 README에 식과 기호를 정리했다.

## 코드 형태

- 헤더만으로 이루어진 C++17 코드다. 함수는 `NFLOW_HD inline`으로 선언했고, CUDA로 컴파일하면 `__host__ __device__`가 붙는다.
- 실수 형식 `nflow::real`은 `double`이다. `NFLOW_USE_SINGLE_PRECISION`을 정의하면 `float`가 되지만, 공개 실행 파일은 배정밀도로 빌드했다.
- 해석기마다 네임스페이스 `nflow::<폴더 이름>`을 쓴다.
- 함수는 해석기의 셀 자료구조 대신 필요한 값을 인자로 받는다. 인자가 많은 경우 그 헤더 안에 작은 구조체를 두었다.

## 실행 파일과의 관계

식은 공개 실행 파일과 같은 소스 커밋(LBM `e20c709`, LBM_DEM `9a73e00`)에서 옮겼다. 옮길 때 바꾼 것은 자료구조 접근을 인자로 바꾼 것, 쓰이지 않는 코드와 내부 주석을 지운 것뿐이고, 계산 순서와 상수는 원본 그대로다.

이를 확인하려고 함수마다 원본 식과 무작위 입력으로 출력을 비교했고, 모든 공개 함수의 결과가 비트 단위로 같았다(MSVC, 배정밀도). 헤더는 배정밀도에서 MSVC(`/W4`)와 CUDA 11.7 `nvcc`로 경고 없이 컴파일된다. 단정밀도로 컴파일하면 원본과 같은 `double` 상수를 `float`에 넣는 자리에서 형 변환 경고가 난다.

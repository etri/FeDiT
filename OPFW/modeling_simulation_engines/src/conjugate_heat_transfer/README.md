# 복합 열전달 해석기 물리 식

복합 열전달 해석기는 유체 영역의 대류와 고체 영역의 열전도를 함께 푸는 격자 볼츠만 해석기다. 온도는 D3Q27 격자의 온도 분포함수 g로 풀고, 유동은 별도의 분포함수로 푼다. 두 장은 이송 속도 u와 Boussinesq 부력으로 연결된다.

고체와 유체의 경계면에는 따로 쓰는 식이 없다. 열을 전달하는 고체 셀도 유체 셀과 같은 온도 식을 쓰되, 속도를 0으로 두고 그 셀 재료의 열확산계수와 열용량을 쓴다. 온도 분포는 경계면을 그대로 지나 이동하고, 유동 분포만 경계면에서 반사된다. 그래서 공액 열전달은 셀마다 다른 재료 상수(`material.hpp`)로 표현된다.

모든 값은 격자 단위이고 시간 간격은 1이다. 실수형은 공통 헤더(`../common/nflow_formula.hpp`)를 따른다.

## 파일별 내용

- `lattice.hpp`: 격자 방향으로의 사영 e_i·v. D3Q27 격자 속도 e_i, 가중치 w_i, 반대 방향 번호는 `../common/d3q27.hpp`에 있다.
- `material.hpp`: 셀 재료의 열 상수. 열확산계수 alpha = k / (rho c_p), 완화 시간 tau_g = 3 (alpha + nu_t / Pr_t) + 1/2, 열원 항 s = q / (rho c_p). nu_t / Pr_t는 난류 열확산계수이고, 층류와 고체에서는 nu_t = 0이다.
- `equilibrium.hpp`: 온도 분포의 평형분포 g_i^eq = T w_i (1 + 3 e_i·u). 속도에 대해 1차다.
- `collision.hpp`: 온도 분포의 충돌. g_i* = g_i^eq + (1 − omega) g_i^neq + (1 − omega/2) w_i (3 e_i·∂(Tu)/∂t + s), omega = 1/tau_g. ∂(Tu)/∂t 항은 1차 모멘트에서 생기는 오차를 보정하고, s는 열원이다. ∂(Tu)/∂t는 한 시간 단계 차이 T u − T_prev u_prev로 계산한다.
- `regularization.hpp`: 충돌 전에 쓰는 비평형 성분 g^neq의 재구성(HR 정칙화). g − g^eq의 1차 모멘트와 유한차분 추정값 −c_s² tau_g ∇T − (1/2) ∂(Tu)/∂t를 가중치 sigma로 섞은 뒤, g_i^neq = 3 w_i e_i·a1로 다시 만든다. 2차 이상의 비평형 모멘트는 스칼라 이송-확산식의 거시 방정식에 들어가지 않으므로 재구성하지 않는다. 등방성 열전도를 전제로 한다.
- `macroscopic.hpp`: 거시 온도 T = Σ g_i + s/2. 충돌과 재구성에 넘기는 셀 상태(현재·이전 시간 단계의 T와 u) 구조체도 여기에 있다.
- `force.hpp`: 온도가 유동에 주는 힘. Boussinesq 부력 F_b = −rho g beta (T − T_ref)는 중력과 운동량 원천항에 더해진다. 합친 힘 F는 유동 분포의 중심 모멘트 충돌에서 1차·3차·5차 중심 모멘트로 들어간다. 이 함수는 그 모멘트 값만 정하고, 나머지 모멘트의 완화는 담지 않는다.
- `boundary.hpp`: 열을 전달하지 않는 고체 벽의 온도 조건. 벽으로 향하는 링크 i마다 반대 방향 분포를 정한다. 등온 벽은 g_opp = −g_i* + 2 w_i T_w(반대칭 반사), 단열 벽은 g_opp = g_i*(반사), 열유속 벽은 g_opp = g_i* + 6 w_i phi, phi = q_w / rho / c_p다. 대류 벽은 q_w = −h (T − T_inf)를 같은 열유속 식에 넣는다. 열유속 식의 rho는 벽 셀의 유체 밀도이고, 움직이는 벽에서는 1을 쓴다. 평형분포로 정하는 입·출구는 경계 온도 T_b로 equilibrium_HR(u_b, T_b)를 쓴다. T_b는 등온이면 주어진 값이고, 단열이면 내부 경계에서는 이웃 셀 온도를 선형 외삽한 값(`extrapolated_temperature`), 계산 영역 바깥 경계에서는 이웃 셀 온도 그대로다.

한 시간 단계에서 온도 식은 충돌, 분포 이동, 경계 조건, 거시 온도, 온도 기울기, 평형분포, 비평형 재구성 순서로 쓰인다. 이 가운데 분포 이동과 온도 기울기 계산은 이 폴더에 없다.

## 주요 기호

| 기호 | 뜻 |
|---|---|
| g_i, g_i*, g_i^eq, g_i^neq | 온도 분포, 충돌 후 분포, 평형분포, 비평형 성분 |
| e_i, w_i | 격자 속도, 가중치 |
| c_s² | 격자 음속의 제곱, 1/3 |
| T, T_prev | 현재·이전 시간 단계의 온도 |
| u, u_prev | 현재·이전 시간 단계의 속도. 고체에서는 0 |
| rho, c_p, k | 셀 재료의 밀도, 정압 비열, 열전도율 |
| alpha | 열확산계수 k / (rho c_p) |
| nu_t, Pr_t | 난류 점성, 난류 Prandtl 수 |
| tau_g, omega | 온도 분포의 완화 시간과 완화율 1/tau_g |
| q, s | 체적 열원과 열원 항 q / (rho c_p) |
| sigma | HR 정칙화의 혼합 가중치, 0~1 |
| g, beta, T_ref | 중력 가속도, 열팽창계수, 기준 온도 |
| q_w, h, T_inf | 벽 열유속, 열전달계수, 자유류 온도 |

## 참고 모델

- 이송-확산 격자 볼츠만 모델: 속도에 대해 1차인 평형분포와 단일 완화 시간 충돌
- HR(hybrid recursive regularization) 정칙화, 1차 Hermite 항만 사용. 원본 주석은 2차 항을 쓰지 않는 근거로 Wang(2015)과 Chai의 연구를 든다. 정확한 서지 정보는 원본에 없다.
- 난류 Prandtl 수로 정하는 난류 열확산(nu_t / Pr_t)
- Boussinesq 근사
- 중심 모멘트 충돌의 외력 항(central-moment forcing)
- 반사(bounce-back)·반대칭 반사(anti-bounce-back) 벽 조건

격자 자료구조, 분포 이동, 다중 격자, 유동 분포의 충돌과 거시량, 난류 점성 nu_t를 구하는 난류 모델은 이 폴더에 없다. nu_t는 입력으로 받는다.

이 폴더는 해석기의 물리 식 부분만 담았으며, 단독으로 빌드되는 해석기가 아니다.

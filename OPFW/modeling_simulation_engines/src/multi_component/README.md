# 다성분(2성분) 해석기 물리 식

NFLOW LBM 다성분 해석기가 두 유체(예: 물과 공기)를 계산할 때 쓰는 물리 식을 모은 헤더다. 두 유체의 분포는 order parameter φ로 나타낸다(무거운 유체 1, 가벼운 유체 0). φ는 보존형 Allen–Cahn 상장 방정식을 분포함수 G로 풀고, 유동은 밀도로 나눠 정규화한 분포함수 F로 푼다. 밀도와 점성은 φ로 보간하며, 표면장력·압력·점성·체적력을 유동에 힘으로 넣는다.

헤더만 있으며 `../common/nflow_formula.hpp`와 `../common/d3q27.hpp`가 필요하다(C++17). 함수에는 `NFLOW_HD`가 붙어 있어 CUDA에서는 호스트와 디바이스 양쪽에서 쓸 수 있다.

## 파일별로 담은 식

`constants.hpp`
- 분모가 0이 되지 않게 더하는 작은 값 ε(배정밀도 1e-12, 단정밀도 1e-6)과 π.

`collision.hpp` (충돌은 중심 모멘트 공간에서 쓴다)
- `flow_relaxation_rate`: F의 전단 완화율 ω = 1/(3ν + 1/2).
- `collision_F_forcing`: F 충돌의 힘 항. a = F/ρ로 두고, 1차 모멘트는 ω₁ = 1로 완화하면서 (1 - ω₁/2)a를 더하고, 3차·5차 모멘트 일부를 a로 정한다. F의 나머지 모멘트 완화는 이 폴더에 없다.
- `phase_field_relaxation_rate`: G의 완화율 ω_g = 1/(3M + 1/2).
- `collision_G_moments`: G의 충돌 후 중심 모멘트 27개. 1차 모멘트는 φu로 완화하면서 경계면 힘 F_φ를 더하고, 나머지는 (φ + S/2)와 F_φ로 정한다.

`force.hpp`
- `interface_normal`: 경계면 법선 n = ∇φ/(|∇φ| + ε).
- `interface_curvature`: 곡률 κ = -∇·n.
- `density_gradient`: ∇ρ = (ρ_H - ρ_L)∇φ.
- `surface_tension_force`: 표면장력 F_s = σκ∇φ · ρ/((ρ_H + ρ_L)/2).
- `pressure_force`: F_p = -∇p.
- `viscous_force`: 밀도 기울기에서 생기는 점성 항 F_μ = ν(∇u + ∇uᵀ)·∇ρ.
- `body_force`: F_b = ρg + s.
- `total_force`: F = F_s + F_p + F_μ + F_b.
- `interface_sharpening_force`: φ 방정식의 경계면 힘 F_φ = 4φ(1 - φ)/(3W) n. 경계면 두께를 유지하는 항이며, 설정값 `miscibility`가 0이면 끈다.

`macroscopic.hpp`
- `macroscopic_order_parameter`: φ = Σg_i + S/2.
- `mixture_property`: q = q_L + φ(q_H - q_L). 밀도 ρ와 점성계수 μ를 이 식으로 보간한다.
- `effective_kinematic_viscosity`: ν = μ/ρ + ν_t.
- `macroscopic_velocity`: u = Σf_i c_i + F/(2ρ). F를 정규화했으므로 1차 모멘트가 곧 속도다.
- `update_pressure`: p ← p + ρc_s²(Σf_i - 1), c_s² = 1/3. 결과는 필터를 거치기 전 압력 p*다.

`filter.hpp`
- `pressure_filter`: 압력 필터. 필터 전 압력 p*를 노드 자신과 이웃 26방향에 대해 가중 평균해 p = Σw_i p*_i / (Σw_i + ε)로 정한다. 이웃이 있는 방향만 더하며 고체 노드도 포함한다. 격자 크기의 압력 진동을 줄이며, 이 p가 압력 힘과 다음 단계의 압력 갱신에 쓰인다.

`boundary.hpp`
- `solid_node_average`: 고체 노드 값을 이웃 유체 노드의 가중 평균 Σw_i q_i / Σw_i로 정한다. w_i는 공통 헤더 `../common/d3q27.hpp`의 `d3q27::weight`(정지 8/27, 면 2/27, 모서리 1/54, 꼭짓점 1/216)다. 해석기는 φ와 압력에 쓴다.
- `wetting_order_parameter`: 접촉각 θ인 벽에서 거리 d만큼 떨어진 곳의 φ. a = d(-4/W)cos θ로 두고 φ = (1 + a - √|(1 + a)² - 4aφ_ref|)/a - φ_ref이며, θ가 90°이면 φ = φ_ref다.

한 시간 단계에서 이 식들은 대략 다음 순서로 이어진다. G에서 φ를 구해 밀도와 점성을 보간하고, F로 압력을 갱신한다. 고체 노드의 φ는 접촉각 조건으로 정하고, 압력은 필터로 고른다. φ의 기울기에서 법선과 곡률을 구해 힘을 계산하고, 그 힘으로 속도를 구한다. 다음 충돌에서 F에는 힘이, G에는 경계면 힘이 들어간다.

## 분포와 모멘트의 순서

분포함수 27개는 방향 (cx, cy, cz)를 i = (cx + 1) + 3(cy + 1) + 9(cz + 1) 순서로 둔다. cx, cy, cz는 -1, 0, +1 중 하나이며, `../common/d3q27.hpp`와 같은 순서다. 중심 모멘트 k_abc(x, y, z 방향 차수 a, b, c)는 a + 3b + 9c 자리에 둔다. `collision.hpp`의 `moment` 네임스페이스에 자리 번호가 있다.

## 주요 기호

모든 값은 격자 단위다.

| 기호 | 뜻 |
| --- | --- |
| φ | order parameter (무거운 유체 1, 가벼운 유체 0) |
| ρ, ρ_H, ρ_L | 밀도, 무거운 유체와 가벼운 유체의 밀도 |
| μ, ν, ν_t | 점성계수, 동점성계수, 난류 점성 |
| u, p, p* | 속도, 압력, 필터 전 압력 |
| F, F_φ | 유동에 넣는 힘(단위 부피당), φ 방정식의 경계면 힘 |
| S | φ의 원천항(시간 단계당) |
| M | φ의 이동도(mobility) |
| W | 경계면 두께 |
| σ, κ, n | 표면장력 계수, 곡률, 경계면 법선 |
| θ, d | 정적 접촉각, 벽까지 거리 |
| ω, ω_g | F와 G의 완화율 |
| c_s² | 격자 음속의 제곱, 1/3 |

## 넣지 않은 것

F와 G의 평형분포(비압축 해석과 같은 표준 평형분포 인수라 넣지 않음), 분포함수와 중심 모멘트 사이의 변환, 유동 분포 F의 cumulant 완화(힘 항 제외), 기울기와 곡률을 구하는 차분 계산, 입구·출구·벽의 일반 경계조건, 난류 모델, streaming, 격자 세분화, 초기화와 격자 자료구조는 넣지 않았다.

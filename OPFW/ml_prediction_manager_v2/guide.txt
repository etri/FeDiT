FeDiT 예측매니저 간소화 설치 가이드
==========================================

문서 상태
---------
- 이 문서는 기존 guide.txt와 기술해설서 2.2.9절의 설치 부분을 간소화한 교체본이다.
- 이번 전달 범위는 코드 배치, 필수 모듈 설치, 서비스 실행, 첫 화면 진입 확인까지이다.
- Dataset·AutoML·Ray·MLflow·KServe 등 2.2.9 전체 기능시험은 다음 요청에서 수행한다.
- NVIDIA 드라이버는 설치·업데이트·재설치하지 않는다.
- GPU 개수, 모델, 드라이버 버전, 최소 VRAM을 nvidia-smi에서 읽어 자동 설정한다.

2. 제공 파일을 codex-ubuntu에 저장
-----------------------------------

다음 세 파일을 아래 위치에 저장한다.

  /home/ubuntu/prediction-manager-work/fedit-repository-replacement-files.gpu.zip
  /home/ubuntu/prediction-manager-work/script.corrected.gpu.zip
  /home/ubuntu/prediction-manager-work/fedit_clean_ubuntu22_v8.corrected.gpu.zip

`fedit-repository-replacement-files.gpu.zip`에는 수정된 FeDiT 파일의 완성본과
설치 스크립트 전체가 상대 경로 그대로 들어 있다. patch를 적용하지 않고
동일 경로에 덮어쓴다.


3. 보완 이미지 빌드 및 실행
----------------------------

codex-ubuntu Docker 호스트에서 실행한다.

  mkdir -p /home/ubuntu/prediction-manager-work
  unzip -oq /home/ubuntu/prediction-manager-work/fedit_clean_ubuntu22_v8.corrected.gpu.zip \
    -d /home/ubuntu/prediction-manager-work
  cd /home/ubuntu/prediction-manager-work/fedit_clean_ubuntu22_v8
  cp -n .env.example .env
  docker compose build --no-cache
  docker compose up -d
  docker compose ps
  ./verify.sh

이 Compose 구성은 `gpus: all`로 기존 호스트 드라이버를 전달한다. 이미지
내부에 NVIDIA 드라이버를 설치하지 않는다.


4. FeDiT 완성 파일 덮어쓰기
----------------------------

FeDiT 저장소가 다음 위치에 이미 있어야 한다.

  /home/ubuntu/prediction-manager-work/FeDiT

Docker 호스트에서 실행한다.

  unzip -oq \
    /home/ubuntu/prediction-manager-work/fedit-repository-replacement-files.gpu.zip \
    -d /home/ubuntu/prediction-manager-work/FeDiT

저장소를 실행 컨테이너에 복사한다.

  docker exec fedit-clean-ubuntu22 mkdir -p /home/ubuntu/prediction-manager-work
  docker cp /home/ubuntu/prediction-manager-work/FeDiT \
    fedit-clean-ubuntu22:/home/ubuntu/prediction-manager-work/FeDiT
  docker exec -u root fedit-clean-ubuntu22 chown -R ubuntu:ubuntu \
    /home/ubuntu/prediction-manager-work/FeDiT

모든 파일의 개별 목적지는 함께 제공하는 FILE_PLACEMENT.tsv에 기록되어 있다.


5. 설치 설정 생성
-----------------

컨테이너에 SSH로 접속한다.

  ssh ubuntu@10.254.85.120 -p 2222

접속 후 다음 명령을 실행한다.

  cd /home/ubuntu/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts
  cp -n verification-install.env.example .verification-install.env

기본 설정은 다음을 자동으로 수행한다.
- nvidia-smi에서 물리 GPU 개수, 모델, 드라이버, 최소 VRAM 탐지
- 최소 VRAM을 12 GiB 단위로 나누어 GPU당 time-slicing 슬롯 계산
- 자동 슬롯을 1~8 범위로 제한
- 물리 GPU 개수를 Ray GPU worker 최대 replica 기본값으로 사용
- NVIDIA Container Toolkit, Device Plugin, DCGM Exporter 설치
- NVIDIA 드라이버 패키지는 설치하지 않음

현재 확인한 4× RTX A6000 환경에서는 GPU당 4슬롯, 총 16개 scheduler
resource로 계산된다. 다른 GPU에서는 실제 개수와 최소 VRAM에 맞춰 달라진다.


6. 필수 모듈 한 번에 설치
--------------------------

컨테이너 SSH 터미널에서 다음 한 줄만 실행한다.

  cd /home/ubuntu/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts && ./01-install-required-modules.sh

이 스크립트가 설치하는 범위:
- Ubuntu 필수 패키지
- Docker, containerd, buildx
- kubelet, kubeadm, kubectl
- Helm, Kustomize
- NVIDIA Container Toolkit

기존 NVIDIA 드라이버는 정상 작동 여부만 확인하며 변경하지 않는다.


7. 서비스 설치 및 실행
----------------------

컨테이너 SSH 터미널에서 다음 한 줄만 실행한다.

  cd /home/ubuntu/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts && ./02-start-prediction-manager.sh

중단 후 재실행할 때도 같은 명령을 사용한다. 완료 단계는
`/opt/prediction-manager-verification/state`에 기록되어 건너뛴다.

스크립트 마지막의 진입 점검 항목:
- Kubernetes API
- Prediction Manager deployment Ready
- Prediction Manager HTTP 진입
- Kubeflow HTTP 진입
- nvidia-smi GPU/드라이버 진입

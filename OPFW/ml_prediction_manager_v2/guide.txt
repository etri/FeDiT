FeDiT 예측매니저 간소화 설치 가이드
==========================================

문서 상태
---------
- 이 문서는 기존 guide.txt와 기술해설서 2.2.9절의 설치 부분을 간소화한 교체본이다.
- 이번 전달 범위는 코드 배치, 필수 모듈 설치, 서비스 실행, 첫 화면 진입 확인까지이다.
- Dataset·AutoML·Ray·MLflow·KServe 등 2.2.9 전체 기능시험은 다음 요청에서 수행한다.
- NVIDIA 드라이버는 설치·업데이트·재설치하지 않는다.
- GPU 개수, 모델, 드라이버 버전, 최소 VRAM을 nvidia-smi에서 읽어 자동 설정한다.


1. 고정 작업 위치
-----------------

호스트:
  /home/$USER/prediction-manager-work

FeDiT 저장소:
  /home/$USER/prediction-manager-work/FeDiT

설치 스크립트:
  /home/$USER/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts


2. git clone
-----------------------------------

git clone -b OPFW_development_ETRI_pman --single-branch https://github.com/etri/FeDiT.git 



3. 설치 설정 생성
-----------------

호스트에 SSH로 접속한다.

접속 후 다음 명령을 실행한다.

  cd /home/$USER/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts
  cp -n verification-install.env.example .verification-install.env

기본 설정은 다음을 자동으로 수행한다.
- nvidia-smi에서 물리 GPU 개수, 모델, 드라이버, 최소 VRAM 탐지
- 최소 VRAM을 12 GiB 단위로 나누어 GPU당 time-slicing 슬롯 계산
- 자동 슬롯을 1~8 범위로 제한
- 물리 GPU 개수를 Ray GPU worker 최대 replica 기본값으로 사용
- NVIDIA Container Toolkit, Device Plugin, DCGM Exporter 설치
- NVIDIA 드라이버 패키지는 설치하지 않음

현재 확인한 4× RTX A6000 환경에서는 GPU당 4슬롯, 총 16개 scheduler
resource로 계산된다. 다른 GPU에서는 실제 개수와 최소 VRAM에 맞춰 달라진다.


4. 필수 모듈 한 번에 설치
--------------------------

컨테이너 SSH 터미널에서 다음 한 줄만 실행한다.

  cd /home/$USER/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts && ./01-install-required-modules.sh

이 스크립트가 설치하는 범위:
- Ubuntu 필수 패키지
- Docker, containerd, buildx
- kubelet, kubeadm, kubectl
- Helm, Kustomize
- NVIDIA Container Toolkit

기존 NVIDIA 드라이버는 정상 작동 여부만 확인하며 변경하지 않는다.


5. 서비스 설치 및 실행
----------------------

컨테이너 SSH 터미널에서 다음 한 줄만 실행한다.

  cd /home/$USER/prediction-manager-work/FeDiT/OPFW/ml_prediction_manager_v2/scripts && ./02-start-prediction-manager.sh

중단 후 재실행할 때도 같은 명령을 사용한다. 완료 단계는
`/opt/prediction-manager-verification/state`에 기록되어 건너뛴다.

스크립트 마지막의 진입 점검 항목:
- Kubernetes API
- Prediction Manager deployment Ready
- Prediction Manager HTTP 진입
- Kubeflow HTTP 진입
- nvidia-smi GPU/드라이버 진입


6. 웹 첫 화면 확인
------------------

브라우저에서 다음 주소를 연다.

  http://localhost:18080/fedit/predictor-creator-tool

서비스 선택 화면에서 다음 항목이 표시되면 진입 점검 완료이다.
- 학습 데이터셋 준비
- AutoML
- Ray
- MLflow
- TensorBoard
- Model Registry
- KServe
- MLOps 모니터링

이번 단계에서는 각 서비스의 전체 기능시험을 수행하지 않는다.

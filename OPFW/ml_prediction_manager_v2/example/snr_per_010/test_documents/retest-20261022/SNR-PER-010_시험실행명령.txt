SNR-PER-010 시험 실행 명령 (결과서 v2.1 10~15쪽)

서버 컨테이너의 같은 Terminal에서 순서대로 실행한다.
노트북 Run All Cells와 Terminal 추론 명령은 둘 중 한 가지만 실행한다.
아래 GitHub clone은 존재하지 않는 새 TRIAL 폴더에서 수행한다.
한글 폰트에서 원화 모양으로 보이는 줄 연결 문자는 ASCII 백슬래시(0x5C)이다.

4.1 단계 2: 작업 변수

이하 명령은 컨테이너의 같은 Terminal에서 순서대로 실행한다. TRIAL은 존재하지 않는 새 폴더로 지정한다.
TRIAL=/home/jovyan/snr-per-010-retest-20261022
PKG=OPFW/ml_prediction_manager_v2/example/snr_per_010
PY=/opt/snr010-env/bin/python
RUN=retest-20261022

4.1 단계 3: GitHub clone 및 시험 커밋 선택

cd /home/jovyan
git clone --depth 1 --single-branch \
  --branch OPFW_development_ETRI_pman \
  https://github.com/etri/FeDiT.git "$TRIAL"
cd "$TRIAL"
git rev-parse HEAD
이번 시험의 소스 커밋은 4ce1a356eb335cda642a09eee2054db31d674c3d이다. 재현 시 아래 명령으로 동일 커밋을 선택한다.
git fetch --depth 1 origin \
  4ce1a356eb335cda642a09eee2054db31d674c3d
git checkout --detach \
  4ce1a356eb335cda642a09eee2054db31d674c3d
git rev-parse HEAD

4.1 단계 4: 모델 복원·환경 확인·데이터셋 다운로드·입력 검증

cd "$TRIAL/$PKG"
"$PY" prepare_weights.py
"$PY" check_reference_runtime.py
"$PY" download_dataset.py --workspace workspace
"$PY" verify_inputs.py --workspace workspace
정상 확인: passed=true, model_files_verified=60, model_hash_mismatches=0, frames_total=8931 및 NVIDIA A40/CUDA를 확인한다.

4.2 단계 3: 실행 위치

cd "$TRIAL/$PKG"
mkdir -p workspace/logs

4.2 단계 4: 추론 및 성능평가 실행

동일한 전체 추론·평가를 Terminal에서 실행할 때는 다음 명령을 사용한다. 로그를 저장하며 기존 백본 캐시는 지정하지 않는다.
nohup "$PY" -u run_inference.py \
  --workspace workspace --run-name "$RUN" \
  > "workspace/logs/$RUN.log" 2>&1 < /dev/null &
PID=$!
echo "$PID"
run_inference.py는 4개 시퀀스의 검출·특징 추출·추적·후처리와 TrackEval 평가, CSV 및 성능 그래프 저장까지 실행한다. 노트북 실행과 Terminal 실행 중 한 가지 방식만 사용한다.

4.2 단계 5: 로그·종료 상태 확인

Terminal로 실행한 경우 다음 명령으로 로그와 종료 상태를 확인한다. 노트북으로 실행한 경우 추론 셀의 오류 없이 Inference and evaluation complete.가 표시되는지 확인한다.
tail -f "workspace/logs/$RUN.log"
로그 표시를 마치려면 Ctrl+C를 누른다. 같은 Terminal에서 다음 명령으로 종료 상태와 최종 로그를 확인한다.
wait "$PID"
echo "$?"
tail -n 20 "workspace/logs/$RUN.log"
정상 확인: 종료 코드 0, MOTA_TARGET_VERIFIED 80.011059%, INFERENCE_AND_EVALUATION_COMPLETE 및 4개 시퀀스 전체 처리 완료를 확인한다.

4.2 단계 6: 그래프·테이블·목표 성능 확인

"$PY" visualize_evaluation.py \
  --workspace workspace --run-name "$RUN"
"$PY" - <<'PY'
import json
from pathlib import Path
p = Path('workspace/results/retest-20261022')
d = json.loads((p/'evaluation/metrics.json').read_text())
r = next(x for x in d['evaluations']
         if x['match_iou'] == 0.1)
for x in r['folds']:
    print(x['sequence'], x['mota_percent'],
          x['fp'], x['fn'], x['idsw'], x['gt'])
print('Mean MOTA (%):', r['macro_mota_percent'])
assert d['complete_four_fold_scope']
assert r['macro_mota_percent'] >= 80
PY
정상 확인: MOTA 산술평균 80.011059%, assertion 오류 없음, visual_evidence/manifest.json의 assets 48개를 확인한다. visual_evidence/index.html에서 그래프·추적·궤적 이미지를 확인한다.
생성 파일: workspace/results/retest-20261022/의 evaluation/metrics.json, sequence_metrics.csv, aggregate_metrics.csv, predictions/, charts/, visual_evidence/. 시험 화면과 그림은 PPTX 및 본 결과서에 저장한다.

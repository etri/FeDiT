# 프로젝트 폴더 구조 설명

이 저장소는 다양한 프로젝트와 기술 문서를 포함하고 있으며, 각 폴더는 특정 기능 또는 영역을 담당합니다. 아래는 디렉토리 구조와 각 폴더의 용도에 대한 설명입니다.

---

## **폴더 구조**

```
/
├── DETRCK                   # 마이크로서비스 오케스트레이션(MSA) 관련 모듈
├── DT1_E8ight               # 테스트 시나리오 관련 코드
├── FAGWS                    # 기술 문서
├── JTP                      # 업로드된 파일들
├── Jinwoo                   # 원격 브랜치 병합 작업
├── MSAOC                    # 기술 문서
├── ONTG                     # 기술 문서
├── dl-2023-1-pklot          # DL 2023-1-pklot 소스 코드
├── ml_knowledge_base        # 머신러닝 관련 지식 베이스 자료
├── ml_prediction_manager    # 머신러닝 예측 매니저 관련 코드
├── traffic_prediction_etri  # 교통 예측 프레임워크
├── .gitkeep                 # 빈 디렉토리 유지용 파일
└── README.md                # 저장소 개요 파일
```

## **폴더 설명**

### **`DETRCK`**
- **목적**: 마이크로서비스 오케스트레이션(MSA) 관련 모듈 코드.
- **최근 작업**: MSA 모듈 수정.

### **`DT1_E8ight`**
- **목적**: 테스트 시나리오 작성 및 실행을 위한 코드.
- **최근 작업**: 테스트 시나리오 업로드.

### **`FAGWS`**
- **목적**: 프로젝트와 관련된 기술 문서 보관.
- **최근 작업**: 기술 문서 업로드.

### **`JTP`**
- **목적**: 다양한 업로드된 파일 관리.
- **최근 작업**: 새로운 파일 업로드.

### **`Jinwoo`**
- **목적**: 원격 브랜치 병합 및 동기화.
- **최근 작업**: 원격 브랜치 병합 수행.

### **`MSAOC`**
- **목적**: 마이크로서비스 관련 기술 문서 보관.
- **최근 작업**: 기술 문서 업로드.

### **`ONTG`**
- **목적**: 기술 문서 및 자료 보관.
- **최근 작업**: 기술 문서 업로드.

### **`dl-2023-1-pklot`**
- **목적**: DL 2023-1-pklot 소스 코드 관리.
- **최근 작업**: 프로젝트 소스 코드 업로드.

### **`ml_knowledge_base`**
- **목적**: 머신러닝 관련 지식 베이스 관리.
- **최근 작업**: 지식 베이스 문서 수정.

### **`ml_prediction_manager`**
- **목적**: 머신러닝 예측 모델 관리 및 관련 코드.
- **최근 작업**: 매니저 관련 README 파일 수정.

### **`traffic_prediction_etri`**
- **목적**: 교통 예측 프레임워크 개발.
- **최근 작업**: 관련 파일 업로드.

### **`.gitkeep`**
- **목적**: 빈 디렉토리의 Git 추적 유지.

### **`README.md`**
- **목적**: 저장소 구조와 개요를 설명.

### **기여 방법**
1. 이 저장소를 클론합니다:
   ```bash
   git clone <repository-url>
   ```
2. 수정할 폴더에서 작업합니다.
3. 변경 사항을 추가하고 커밋합니다:
   ```bash
   git add <파일 경로>
   git commit -m "변경 사항 설명"
   ```
4. 원격 저장소에 푸시합니다:
   ```bash
   git push origin <브랜치 이름>
   ```

• Accuracy & Loss는 모델의 성능을 판단하는 기준입니다.

  • epochs : 훈련 횟수 (한 번의 전체 데이터 학습 = 1 epoch)
    loss : 훈련 데이터에 대한 손실값 (MSE나 MAE 등)
    val loss : 검증(validation) 데이터에 대한 손실값
    mae : Mean Absolute Error (훈련 데이터 기준 예측 오차 평균)
    val mae : 검증 데이터 기준 MA

epochs loss val loss mae val mae

  • 모델이 얼마나 잘 학습하고 일반화하고 있는지를 알려주는 핵심 지표입니다.

  • Training Loss : 학습(training) 데이터에 대해 모델이 예측한 결과와 실제 값의 차이 (오차)
    Validation Loss : 검증(validation) 데이터에 대해 모델이 예측한 결과와 실제 값의 차이 (오차)

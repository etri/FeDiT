    pip-licenses --format=plain --with-urls --with-authors

**LGPL v2.1과 Apache License 2.0의 관계**

Free Software Foundation은 Apache License 2.0의 특허 조항 때문에 이를
GPL v2 / LGPL v2.1(버전 단독 표기)과 비양립으로 봅니다. 위 목록의 Apache 계열
28개(26 + 이중 2)가 이에 해당합니다.

본 프로젝트의 라이선스는 상위 프로젝트(FDTFW)의 방침에 따라 **LGPL v2.1로
고정**되며 "or later"를 채택하지 않습니다. 위 양립성 쟁점이 본 프로젝트에
적용되지 않는 근거는 다음과 같습니다.

  - 해당 패키지들은 본 프로젝트의 배포물에 포함(bundle)되지 않습니다.
    저장소에는 `requirements.txt`의 패키지명과 버전만 기재되어 있고, 실물은
    설치 시점에 PyPI에서 각각 내려받아 이용자가 원 라이선스로 직접 취득합니다.
  - 따라서 본 프로젝트를 배포하는 행위에는 Apache License 2.0 저작물의 배포가
    포함되지 않으며, 결합저작물(combined work)의 배포도 발생하지 않습니다.
    이는 GPL FAQ가 말하는 병렬 배치(mere aggregation)에 해당합니다.
  - 비양립 문제는 두 라이선스의 저작물을 하나의 배포물로 묶어 배포할 때
    발생하는 것이므로, 위 구조에서는 성립하지 않습니다.

**따라서 향후 Apache License 2.0 구성요소의 소스를 본 저장소에 직접 포함시키는
것은 금지됩니다.** 그 시점부터는 위 근거가 무너져 실제 비양립 상태가 됩니다.
새 의존성을 추가할 때는 (a) pip 의존성으로만 둘 것, (b) 소스를 저장소에 넣어야
한다면 라이선스가 LGPL v2.1과 양립하는지 먼저 확인할 것 — 이 두 가지를
반드시 지켜야 합니다.

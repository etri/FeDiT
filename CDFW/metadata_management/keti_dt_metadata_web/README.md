# KETI_DT_METADATA_WEB

디지털트윈 메타데이터 web

### 과제명: 지능형 디지털 트윈 연합 핵심기술 개발

    - 소속: (2세부) 지능형 디지털 트윈 연합 객체 구성 및 데이터 프로세싱 기술 개발
    - 담당: 단일 디지털트윈 메타데이터 생성, 저장, 검색 및 제공 기술, 프레임워크 개발

REST API 호출 방법 (외부 시스템)
POST-
       본문: Push JSON (메뉴바 [Push JSON] 과 같은 multi_load 패킷) → 200 { request_id, status: "pushed" }
POST-
       본문: Run JSON (multi_run_loaded) + "request_id" → 202 { status: "queued_run" }
GET-
       status: pushed → queued_run → running → succeeded / failed, 결과는 outputs[]
* /simulation 프리픽스 없이 (예: -) 호출해도 같습니다. RUN 이 끝나면 엔진이 정리되므로 다시 실행하려면 PUSH 부터 다시 합니다.

연합트윈 CFD 렌더러 프로토타입

도시 CFD 해석의 입력을 만들고(전처리), 해석엔진으로 실행하고(물리 시뮬레이션), 결과를 가시화(후처리)하는 세 페이지입니다.

1

전처리

해석기 고르기 → 형상(STL)과 계산 영역 → 핵심 값 수정 → 해석 실행 또는 입력 JSON(+STL) 내려받기

 2

물리 시뮬레이션

입력 JSON+STL 받기 → 해석기 고르기 → 해석엔진 실행 → 진행 상황 → 가시화

 3

후처리

해석 결과 폴더·ZIP 열기 → Slice·Glyph·Streamline·Isosurface → 저장 시점 재생 → PNG 캡처

2단계(물리 시뮬레이션)는 전처리의 '해석 실행'으로 넘어오거나, 입력 JSON과 STL을 직접 올려 시작합니다. 해석이 끝나면 '가시화'로 후처리가 열립니다.

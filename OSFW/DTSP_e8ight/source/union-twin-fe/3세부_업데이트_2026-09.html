03FEDIT 서비스 디스크립션 도구 개선

데이터 모델링

  • Relationship model Type을 모델 목록에서 검색·선택(URN 자동), 배지 클릭 시 해당 모델로 이동
  • Ready 모델 버전업 후 재편집, Ready 모델 삭제 허용(경고 분리), Ready 시 컨텍스트 자동 재등록
  • 속성 패널 model Type 전체 이름 표시, 버전업 API 명세 불일치(400) 수정

수집 설정 (Agent · Translator)

  • 노코드 매핑 — 원천 JSON 샘플 + 모델 속성으로 Translator 코드 생성, 여러 엔티티 정의, 코드↔폼 동기화, NDXPRO 컴파일 통과 신규
  • 출력 미리보기 — 현재 코드 기준 예상 NGSI-LD 엔티티 계산 · 작성 가이드 모달(HTML 다운로드) 신규
  • Agent/Translator 런타임 로그 뷰(레벨·검색·설정 덤프 접기), translator 수정 저장·target topic, 기본 토픽 fdt_topic/ngsild_topic 통일

수집 현황 (통계)

  • 통계 라이브 워크벤치 개편, 미사용 통계 API 3종 연동·지표 보강
  • 수집 실패 로그: 최신순·KST 고정 표시·날짜 선택, translator 화면에서 fail log 탭

엔티티 조회 · 공통 UX

  • 트리에서 속성이 모델로 표시되던 문제, 엔티티 목록 /iot 경로 제거
  • 오버플로/말줄임 전면 정비, 통계 카드 레이아웃 붕괴 수정

04안정성 · 플랫폼 (BFF 서버 포함)

  • 전 도메인 버그 감사 — 인증 토큰 갱신/쿠키 처리, 요청 처리율 제한(identity throttler), 입력 바이트 길이 검증, 비밀번호 규칙, 작성자 삭제 시 공지 보존(마이그레이션) 등 데이터 손실·인증 결함 수정
  • 독립 레포 분리(모노레포 → union-twin), Dockerfile 통합·Jenkins 정리, 공용 UI 라이브러리 @e8ight/ui 0.2.9 재동기화
  • 미사용 코드 제거 및 로직 단순화 (client/server 전역)

수집 데이터 흐름

원천 JSON──▶ Agent──▶ fdt_topic──▶ Translator──▶ ngsild_topic──▶ Broker

원천 데이터가 Agent · Translator를 거쳐 NGSI-LD 엔티티로 브로커에 저장되기까지의 흐름과 설정 규칙을 정리한 참고 문서입니다. 코드 블록은 우측 상단 버튼으로 복사할 수 있습니다.

토픽 연결 규칙

rule
Agent.targetTopic      == Translator.sourceTopic   ← 반드시 일치 (직접 지정)
Translator.targetTopic == ngsild_topic             ← 고정 기본값, 변경 금지
이 두 줄이 어긋나면 코드가 정상이어도 브로커에 엔티티가 들어오지 않습니다.

전체 작업 순서

  1. 원천 데이터를 확인합니다 (샘플 JSON 확보).
  2. 데이터 모델링을 진행합니다 (type, attribute, valueType 정의).
  3. Translator 코드를 작성합니다 (원천 + 모델 + 샘플 코드 → AI 요청).
  4. Agent를 등록합니다 (Target Topic = fdt_topic).
  5. Translator를 등록합니다 (Source Topic = fdt_topic, Target Topic = ngsild_topic).
  6. 브로커에서 엔티티를 조회해 검증합니다.

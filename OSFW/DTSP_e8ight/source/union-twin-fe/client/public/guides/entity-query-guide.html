엔티티 조회

조회는 전체 조회와 단건 조회 두 가지를 사용합니다. 두 경우 모두 Header의 Link에 context 값을 넣어야 합니다.

아래 요청의 서버 주소(ndxpro-server, ndxpro-server)와 context URL은 예시입니다. 실제로는 사용 중인 FEDIT 인스턴스의 브로커 서버 주소와 해당 모델의 context URL로 바꿔서 요청해야 합니다.

URN 인코딩

Entity ID는 URN 형식이라 콜론이 포함됩니다. 경로에 넣을 때는 반드시 인코딩해야 합니다.

전체 조회 (QueryDto)

QueryDto(id, type, q) 로 NGSI-LD Entity 전체를 조회하는 API입니다.

endpoint
GET /ndxpro/v1/broker/entities

Parameters

Name위치타입기본값예시설명
idquerystring—urn:e8ight:Link:10280Entity ID
typequerystring—LinkEntity Type
qquerystring—carriagewayWidth==3조건식
offsetqueryint3200시작 위치
limitqueryint325050조회 건수
sortquerystringDESCASC / DESC정렬 방향
sortpropertyquerystringmodDatemodDate정렬 기준 속성
optionsquerystring—count부가 옵션
Linkheaderstring—<http://context-server:53005/e8ight-context-v1.0.1.jsonld>;모델의 context URL (예시 주소)

q 파라미터 규칙

q의 key 값은 attribute 또는 child attribute name 입니다. 연산자별로 지원되는 attribute value type은 다음과 같습니다.

연산자지원 value type
==String, DateTime String, Boolean, Integer, Double
~=String
<= / >=DateTime String, Integer, Double
== 와 ~= 연산자의 경우, entity id key(_id.id)와 entity service path key(_id.servicePath)도 지원합니다.
q 예시
carriagewayWidth==3
_id.id~=Link
observedAt>=2026-08-25T00:00:00.000Z

요청 예시

curl · 전체 조회 (주소는 예시)
curl -X 'GET' \
  'http://ndxpro-server:54011/ndxpro/v1/broker/entities?type=Link&q=carriagewayWidth%3D%3D3&offset=0&limit=50&sort=DESC&sortproperty=modDate&options=count' \
  -H 'accept: */*' \
  -H 'Link: <http://context-server:53005/e8ight-context-v1.0.1.jsonld>;'
Swagger UI의 Try it out으로 보낼 때는 자동 인코딩되므로 q에 carriagewayWidth==3을 그대로 넣으면 됩니다.

단건 조회

Entity ID를 경로에 직접 넣어 한 건만 조회합니다.

endpoint
GET /ndxpro/v1/broker/entities/{URL-encoded EntityId}
curl · 단건 조회 (주소는 예시)
curl -X 'GET' \
  'http://ndxpro-server:54011/ndxpro/v1/broker/entities/urn%3Angsi-ld%3AFdtParking%3AKR-109012-0004' \
  -H 'accept: */*' \
  -H 'Link: <http://context-server:53005/fdt-twin-context-v1.0.1.jsonld>;'
경로형 단건 조회는 Link 헤더가 없으면 Not Found Entity … context = null(404)로 응답합니다. 헤더 없이 조회하려면 아래처럼 id 쿼리 파라미터를 사용합니다. 연합 객체의 dataAccessURL도 이 형식으로 등록됩니다.
curl · 단건 조회, 헤더 없이 (주소는 예시)
curl -X 'GET' \
  'http://ndxpro-server:54011/ndxpro/v1/broker/entities?id=urn:ngsi-ld:FdtParking:KR-109012-0004'

조회가 안 될 때 체크리스트

  1. 단건 조회에서 URN을 인코딩했는지 확인합니다 (: → %3A).
  2. Link 헤더의 context URL이 해당 모델의 context와 맞는지 확인합니다.
  3. Translator가 만든 entity id와 조회하는 id가 정확히 일치하는지 확인합니다.
  4. Translator Target Topic이 브로커가 구독하는 토픽(ngsild_topic)과 일치하는지 확인합니다.
  5. Agent가 실제로 데이터를 수집·발행하고 있는지 토픽 메시지로 확인합니다.
